# The Rust recorder's honesty ledger — the index: promise → falsifier

The two-column list of [`rust/HONESTY.md`](HONESTY.md), **moved here 2026-09-05
(rung 3's final fix wave) so that file stays under 800 lines**. The split
`docs/CARRIED-DEBT.md` asked to be chosen deliberately rather than discovered
at the ceiling; this is that choice, and the rows are unchanged in wording and
order except row §11's column clause, which this wave widened to the two places
the 2026-09-04 acceptance record's §5.4 states.

A promise with no falsifier is not a promise, it is an assertion, and the
ledger does not carry assertions: every row below names a corpus case, a test,
a vector or an acceptance endpoint, by path.
