# Planning records

This directory was `docs/superpowers/`. It holds the plans, specs, acceptance
records, and spikes for each slice.

Citations inside those files still say `docs/superpowers/`. The records are
historical and many are byte-locked: a test hashes a section of the working
tree against the text an old commit stored, so the bodies are not edited.
When a record says `docs/superpowers/...`, read that path as
`docs/planning/...`.

`git show <commit>:docs/superpowers/...` is still the right spelling for a
commit from before the move. Those commits have the files at the old path.
